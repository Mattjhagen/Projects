# Acme Home Services Website

A modern 5-page website for Acme Home Services, a plumbing & HVAC repair company in Chicago.

## Features

- Responsive design
- Clean, warm, premium aesthetic
- No corporate blue tones
- 5 pages: Home, About Us, Services, Pricing, Contact

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Development

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

The site can be deployed to Vercel, Netlify, or any other static hosting provider that supports Next.js.
